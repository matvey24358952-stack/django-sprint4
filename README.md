# Blogicum («Блогикум»)

Учебный проект курса «Бэкенд-разработчик» Яндекс Практикума — блог-платформа,
в которой пользователи публикуют посты, объединяют их по категориям и
обсуждают в комментариях.

**Автор:** Матвей Швецов
**Группа:** 8к32

## Возможности

- лента публикаций с пагинацией;
- страницы категорий и профилей пользователей;
- регистрация, вход и выход, смена и восстановление пароля;
- создание, редактирование и удаление собственных публикаций (в том числе
  с изображением);
- комментарии к публикациям: добавление, редактирование и удаление;
- отложенные публикации, скрытие постов и категорий;
- собственные страницы ошибок 403, 404 и 500;
- адаптивная вёрстка на Bootstrap 5.

## Стек

- Python 3.13
- Django 5.1
- SQLite
- django-bootstrap5
- Pillow

## Установка и запуск

```bash
git clone https://github.com/matvey24358952-stack/django-sprint4.git
cd django-sprint4

python -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate           # Windows

pip install -r requirements.txt

cd blogicum
python manage.py migrate
python manage.py loaddata ../db.json   # демонстрационные данные
python manage.py runserver
```

Сайт будет доступен по адресу <http://127.0.0.1:8000/>.
